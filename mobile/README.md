# mobile/ — React PWA (Phase 5 · owner: Neha)

Create with Vite (`npm create vite@latest . -- --template react`), build to `mobile/dist/`;
the backend serves it at `/app/` automatically. Set `base: '/app/'` in vite.config.
Run `npm install` while there is Wi-Fi and commit the lockfile.
Commands are `{type:"cmd", id, player, action, ...}`; see `shared/schema.json` → `$defs/cmd`.
